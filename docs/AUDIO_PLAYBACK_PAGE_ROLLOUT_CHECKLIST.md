# 音频专业播放页上线检查清单

> 对应阶段：Phase 6

## 1. 范围说明

本清单用于在专业播放页上线前后，确认以下内容已经收口：

- 页面主播放体验
- 全局播放器与播放页同步
- 队列播放与来源上下文
- 登录态互动
- 移动端 / 桌面端行为
- 浏览器自动播放与媒体失败边界

## 2. 上线前检查

### 2.1 构建与部署

- `pnpm --filter web build` 成功
- 生产前端已重建并重启
- `/audio/works/[id]` 已部署到最新构建版本

### 2.2 配置

- `NEXT_PUBLIC_API_URL` 在生产中要么明确为可访问 API 地址，要么留空走 `/api/v1`
- `NEXT_PUBLIC_WS_URL` 如未显式配置，确认当前 host 下的 `/ws/*` 代理可用
- 前端 rewrite 已正确代理 `/api/*` 和 `/ws/*`

## 3. 核心收听流

### 3.1 从列表页进入

- 在首页点击音频卡片播放按钮
- 底部播放器开始播放
- 打开对应 `/audio/works/[id]`
- 页面显示当前队列来源标签
- 队列高亮与底部播放器当前曲目一致

### 3.2 从详情页开始播放

- 直接打开 `/audio/works/[id]`
- 点击“开始播放”
- 底部播放器同步显示同一首作品
- 页面主按钮切换为“暂停播放”

### 3.3 连续收听

- 点击“下一首”
- 路由跳转到下一首的 `/audio/works/[id]`
- 页面内容更新为下一首
- 底部播放器同步到下一首

- 点击“上一首”
- 在当前播放时间小于 3 秒时切到上一首
- 在当前播放时间大于 3 秒时回到本首开头

### 3.4 队列点击

- 在右侧队列点击任意作品
- 页面跳转到对应 `/audio/works/[id]`
- 当前播放切换到点击作品

## 4. 控制项检查

### 4.1 播放 / 暂停

- 页面主按钮和底部播放器按钮状态同步
- 在页面暂停后，底部播放器同步暂停

### 4.2 进度条

- 当前页面作品正在播放时可以拖动进度条
- 当前页面作品未在播放时，进度条不可误操作

### 4.3 音量

- 调整页面音量后，底部播放器实际音量同步变化
- 音量在切歌后保留

### 4.4 循环 / 随机

- 循环模式能在 `off -> all -> one` 之间切换
- 随机模式切换后状态保留在当前 session 中

## 5. 登录态与互动

### 5.1 未登录

- 可进入播放页
- 可开始播放
- 点赞 / 收藏按钮禁用
- 评论输入区显示登录提示

### 5.2 已登录

- 点赞成功后状态刷新
- 收藏成功后状态刷新
- 发表评论后评论列表刷新
- 举报弹层可展开、提交、关闭

## 6. 页面数据检查

- 当前作品信息显示正确
- 发布时间、标签、时长显示正确
- 创作者更多作品不包含当前作品本身
- 推荐继续收听不包含当前作品本身

## 7. 浏览器与媒体边界

- 音频 URL 失效时，页面不能崩溃
- 浏览器阻止自动播放时，页面至少保留可手动播放能力
- 页面刷新后，当前路由作品可重新进入播放

## 8. 移动端检查

- iPhone / Android 常见宽度下主控制区不溢出
- 底部全局播放器不遮挡评论输入按钮
- 队列、推荐、评论可正常纵向滚动

## 9. 发布后观察项

- `/audio/works/[id]` 页面访问量
- 平均停留时间
- 点赞、收藏、评论转化
- 播放失败率
- 自动播放失败率

## 10. 当前阶段结论

当前阶段没有新增后端接口作为硬依赖。

现有播放页已通过以下前提完成首版上线能力：

- 复用现有作品详情接口
- 复用现有评论与互动接口
- 复用现有用户公开音频列表接口
- 复用公开音频列表接口作为推荐来源

后续如果要提升质量，可以再新增：

- 专门的相关推荐接口
- 播放历史与继续收听接口
- 播放计数与埋点事件上报
